# Agent Workshop Sandbox

A tiny sandbox for the **IEEE × Claude — "Workflows vs Agents in Claude Code"** workshop.

You'll build **two** things in Claude Code and run them on the same little project:

- a **workflow** — `/status-report` — *you* script the steps
- an **agent** — `status-reporter` — *it* decides its own steps and verifies its work

Then you'll watch them disagree about whether a feature is done — and understand exactly why.

**Order:**
1. **`SETUP.md`** — do this *before* the workshop (5 min).
2. **`EXERCISE.md`** — do this *during* the workshop.
3. Stuck? Finished versions are in **`solution/`**.

No Python, no MLflow, no API keys — everything here is reading and writing text files in Claude Code.
