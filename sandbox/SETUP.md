# SETUP — do this BEFORE the workshop (5 minutes)

We start building in the first 20 minutes. **Setup is not part of the session** — please arrive ready.

## 1. Install Claude Code and sign in
Install Claude Code, then run `claude` once and confirm it replies to a message. (Install docs: your invite email / docs.claude.com.)

## 2. Get the repo
Clone it and `cd` into the **sandbox** folder:
```
git clone https://github.com/MaxyMeanderings/claude-code-workshop.git
cd claude-code-workshop/sandbox
```

## 3. Smoke test (proves you're ready)
Start Claude Code in the `sandbox` folder and paste one line:
```
claude
```
```
> Read project/TODO.md and tell me what three features it lists.
```
If you get back three features (auth, export, search), **you're ready.** ✅

## If your laptop fights you
- Use **claude.ai/code** in the browser, or
- **Pair up** with a neighbor — one working setup beats two broken ones.

You do **not** need Python or MLflow for the exercise.
